🏨 Hotel Booking Data Analysis

📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of hotel booking data using Python. It explores booking patterns, customer behavior, cancellations and revenue-related trends.

🎯 Project Objective

To analyze hotel booking information and identify useful patterns and insights through data analysis and visualization.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

📊 Dataset Information

The dataset contains hotel booking records with 32 columns, including:

- Hotel
- Is Cancelled
- Lead Time
- Arrival Date
- Adults and Children
- Stays in Weekend and Week Nights
- Customer Type
- Market Segment
- Average Daily Rate (ADR)
- Reservation Status

🔍 Project Workflow

1. Import Python libraries.
2. Load the hotel booking dataset.
3. Explore dataset structure and information.
4. Perform data preprocessing.
5. Calculate total stay duration.
6. Analyze booking lead time and monthly patterns.
7. Explore customer types and market segments.
8. Visualize findings using Matplotlib and Seaborn.
